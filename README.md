# 🇰🇷 Busan 6 Days Travel App

2026/10/1–10/6 釜山旅行行程 Web App。

## GitHub Pages
1. 將 `index.html` 放在 repository 根目錄。
2. Settings → Pages → Build and deployment → Source: Deploy from a branch。
3. Branch 選 `main`，Folder 選 `/(root)`，Save。
4. 等待部署完成後，點 Visit site。
